# 业务过程还原

执行前阅读 [工具契约](references/contract.md)，需要字段详情时查 [JSON Schema](references/schema.json)。用 `trade_buyer_research(action="deal-timeline", data=...)` 真正执行，工具不可用如实报告。

提取events并引用原文，保留actor、version；日期不明先追问，不能用导入时间替代发生时间。计划用planned，只有真实执行证据才用actual。工具按时间排序并保守标记重复及同版本计划/实际差异；重复候选仍需核对，不以逾期无回执推断确定未执行。不同版本不可直接配对。结合原文补充转折点及需求变化，冲突不静默覆盖。

复用现有沟通纪要及利润计算，不生成无依据商业承诺。本技能输出内部待审复盘草案，不自动发送、建立提醒、写CRM或更新知识库。保留原文证据、未知项及各阶段跳过原因。

## 验收与效果

关键事件召回率=正确提取关键事件/人工标注关键事件；事件准确率=时间、内容、参与方均正确事件/抽查事件；来源可追溯率=可定位原文事件/全部事件；计划误判实际次数验收为0；使用可比材料测量准备时间。

用独立人工标注材料验收提取与判断，计算用人工核算对照。每项报告样本数、分子分母、周期和适用范围，未测不填写准确率。业务改善使用固定观察期及可比商机验证，不将自然推进全部归因于技能。
