# 最终订单条款核对

执行前阅读[工具契约](references/contract.md)，字段详情见[输入Schema](references/schema.json)。调用`trade_buyer_research(action="order-reconciliation", data=...)`，工具不可用时如实说明。

对各文件提取terms并保存document_id和version，不用最新文件自动覆盖旧约定。覆盖主体、SKU规格、数量单位、币种单价金额、付款节点、交期起算条件、贸易术语版本与地点、包装质检文件。程序仅保守比较字段文本；同义、单位换算及语义一致性结合原文审核，不自行标等价。相同字段多版本有差异保持冲突，confirmed只用于真实确认资料。金额计算可调用制单分支核算货品小计，其他费用另列。

只返回内部待审材料，不自动发信、签署、认领收款、写CRM或启动履约。复用背调核验主体、谈单确认条件、沟通生成消息，不重复执行无关触达。来源引用仅说明原文关联，不能独立证明真实性。

## 验收与效果

差异召回率=检出真实差异/人工标注差异；误报率=误报差异/标记差异。分别核验规格、主体、币种、付款与交期关键字段；确认后改单率区分核对遗漏与客户新需求。

用独立人工标注材料验证提取与状态，金额以人工核算对照；覆盖缺项、版本冲突、错误账户、未来记录、混合币种及不同付款方式。每项指标报告样本数、分子分母和观察周期，未测保持未知；业务改善需在可比客户和订单上观察，不把全部成交归因于技能。
