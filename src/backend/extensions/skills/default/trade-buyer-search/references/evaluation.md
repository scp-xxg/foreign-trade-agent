# 买家搜索评估口径

- 候选数：本轮去重、排除后的网站数量，不代表已获客数。
- 审核覆盖率：已标注候选（含证据不足）÷ 本轮候选；同时报告未审核数。
- 有效线索率：人工认为适合进入背调数 ÷（适合数 + 不适合数）。证据不足排除分母，必须另外报告其数量，避免隐藏不确定性。
- 有效线索产出率：适合数 ÷ 全部候选，未审核保留未知；小样本应附原始计数。
- 单条有效线索成本：（同一批搜索/模型实际费用 + 按约定计入的人工成本）÷ 适合数。没有账单或适合数为零时显示未计算，不能以候选数替代适合数。当前页面未接入账单。
- 时间效率：总耗时及适合数/人工工作小时；后端 elapsed_seconds 仅本轮搜索墙钟时间，不能代替人工工时。
- 域名去重不能作为集团去重或真实企业唯一性保证。证据可追溯率应核对每条来源、查询和时间，并抽查网页是否确实支持判断。

验证集按产品/市场分层，保留画像版本、预算、候选、标签和评审时间。比较同预算基线与新策略，尽量盲审；对分歧先写明“适合进入背调”的商家标准。相同画像下网站样本不宜重复计数。持续观察后续背调通过率、有效回复率和成交率，但不能把搜索工具的改动直接认定为成交增长原因。
