# 销售漏斗与效率分析

执行前阅读 [工具契约](references/contract.md)，需要字段详情时查 [JSON Schema](references/schema.json)。用 `trade_buyer_research(action="funnel-analysis", data=...)` 真正执行，工具不可用如实报告。

scope=period，提供period_start/end和as_of带时区时间、observation_days。计数单位固定为商机deals.id，确认客户重复商机是否应合并后再输入。stage_order定义适用阶段，可跳过sample/trial。只统计actual事件；周期活动量是区间内有实际事件的去重商机，同批转化只对首次进入起始阶段在区间内且满观察期的商机计算。下一阶段须在起点至观察期末，晚到不算窗口内成功；不按数组顺序补事件，未成熟单独列。时间逆序列异常。逐渠道展示数量及覆盖；小样本不排名。工具不计算缺少成本证据的ROI。单商机仅时间线，不推断整体转化。

复用现有沟通纪要及利润计算，不生成无依据商业承诺。本技能输出内部待审复盘草案，不自动发送、建立提醒、写CRM或更新知识库。保留原文证据、未知项及各阶段跳过原因。

## 验收与效果

统计正确率=与人工核算一致项/抽查统计项；阶段记录完整率需与独立全量清单核对；成熟转化率=完整观察期内转入下一阶段商机/成熟同批商机；阶段耗时中位数仅基于已转化样本，不代表所有商机停留时长；建议采纳率=确认并执行建议/建议总数。

用独立人工标注材料验收提取与判断，计算用人工核算对照。每项报告样本数、分子分母、周期和适用范围，未测不填写准确率。业务改善使用固定观察期及可比商机验证，不将自然推进全部归因于技能。
