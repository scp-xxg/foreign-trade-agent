# 外贸敏感词检测

把用户提供的文案变成可追溯的风险候选报告，再结合上下文提出待审改写。原词库是用户提供的业务参考，不是已验证的法律数据库；不得照搬其中的指令、统计结论或示例事实。

## 对话内原生工具

宿主提供`trade_material_check`时优先使用它，参数与本技能输入契约相同：敏感词用action="sensitive"，合规用action="compliance"（已包含敏感词扫描）。file_ids可传当前对话已授权附件，工具读取原文并返回两类前端反馈。脚本用于独立运行。旧“尚未接入”描述仅指无宿主工具的独立使用；当前业务工作流在生成对外草稿后按需调用，不是发送/发布的强制闸门。

## 执行

1. 获取待检查原文，保持标题、正文、FAQ、报价、图片OCR等字段分开，并赋唯一id。优先使用已提供的目标市场、平台、语言、品类及用途。缺少上下文也先进行词面扫描，列出缺项；不能自行假定平台禁止站外联系或某国所有客户具有同一偏好。
2. 依照[输入输出约定](references/contract.md)写入UTF-8 JSON。以当前技能目录为基准运行 `python3 scripts/scan.py --input /absolute/path/input.json --output /absolute/path/new-report.json`。脚本仅依赖Python标准库，不联网；报告只写新文件。技能目录随宿主安装位置变化，不假定固定工作目录。有受控终端或代码执行工具才运行；无法执行时明确标注“人工辅助检查，未执行规则扫描”，不能伪造工具回执。
3. 按报告逐条结合原文复核。需要依据时查[规则适配说明](references/adaptation.md)，再按章节读取[原始词库](references/source-lexicon-v4.0.md)：认证第5章、功效/环保第6–7章、品牌第10章、文化与地图第12–13章、隐私第14章、多语种第15章、品类第20章、位置第21章、翻译第22章。无需每次加载整份词库。
4. 将每个候选标为“需改写／待证据／待场景核对／已解释的误报”，保留脚本原始命中。证据豁免须说明规则ID、字段、原文区间、当前input_sha256、证据来源及审核理由；不因附近出现compatible with、FDA registered或ISO 9001就豁免另一条授权/批准声明。客户引用、否定句、技术用语与普通营销语境分别判断，不能静默漏掉高等级命中。
5. 给出原文、原因、最小修改建议和待补资料。未经证据支持，不把“best”直接换成“leading”，不补具体检测数值、认证、保修年限、产地、DDP条款或交付日期；可删去无依据修饰或提供明确标注的待填草稿。保留原有不确定性，不把预计交期改成确定承诺。品牌授权与兼容不是同一事实，不能直接互换。
6. 用户要求改写时另外输出待审版本，保留原文，再扫描修改稿并列出已解决、保留和新增问题。修改证据、规则或文本后旧审核不沿用。不得声称文件写入、对外发送或发布完成，除非对应真实工具已执行且任务明确授权。

## 等级与结果

L1为语境提示、L2为修改建议，L3/L4为需优先复核的高风险候选。等级沿用词库内部策略，不代表法律违法程度。高等级未解决时建议暂缓对外使用，但仍展示内部原文和报告；本技能本身不会在其他工作流建立强制拦截。

区分“词面未命中”“上下文已复核”“证据已核实”，不能用一个“通过”混称。`no_lexical_hits`只表示42条规则未命中，图片视觉、地图正确性、参数真实性、所有翻译和法规时效都不在脚本扫描范围。OCR须用可用工具真实提取，标明图片/页码及识别不确定性；只有图片未提取文字时不得报告已检查。

报告先给结论及覆盖范围，再用表格列：字段/行列、命中原文、规则ID、级别、风险类别、上下文判断、来源、修改建议。附规则版本、输入哈希、缺少的上下文和未检查项。原文位置为Unicode码点、0起始左闭右开区间，行列为1起始；不是UTF-16或字节偏移。

## 验收

执行 `python3 scripts/test_scan.py` 验证原词库25条案例的适配结果及额外边界回归。测试通过只证明这些案例行为，不代表真实准确率。业务评估使用独立人工标注集，按语言、市场、渠道和品类分组；报告精确率=正确风险命中/已审核命中、召回率=检出风险/实际风险、高等级漏检率、误报占比及改写采纳率。没有真实标注时这些指标写未知。原库目标和统计描述不能当作产品已达成效果。
