# 内部核验问题清单

以下19类问题吸收Max-channel的流程设计，用来定位需要哪些资料。它们不是自动执行的法条、不是已核验法规包、也不代表覆盖所有国家。当前程序规则与官方案例必须通过trade_review knowledge真实读取；超出覆盖时明确“待专项核查”。不相关的业务阶段可跳过并写理由，不能伪造“不适用”证据。

| 核验主题 | 适用时询问/核对什么 | 自动能力边界 |
|---|---|---|
| 产品与商业声明 | 参数、价格、交期和保修的来源是否明确 | 当前报价/词库/部分宣称提示，非所有事实鉴真 |
| 主体、产地与授权 | 合同主体、制造地点、品牌授权的资料是否一致 | 美国原产地案例可提示；不核发产地或授权证明 |
| 订单责任条款 | 数量、币种、费用范围、Incoterm、付款和责任的确认依据 | 既有报价一致性检查，不判断全部合同法律效力 |
| 交付文件 | 单证、商品型号/批次和收货信息是否一致 | 未接关务系统，不自动放行出货 |
| 营销与个人数据 | 来源、用途、拒绝联系记录及适用地域是否明确 | 不将公开邮箱等同于营销授权 |
| 欧盟适用范围 | 产品用途、经营者角色、成员国及行业特别规则 | CE/GPSR案例只做限定范围提示 |
| 欧盟食品接触 | 是否实际用于接触食品，材料/测试与用途是否匹配 | 没有专门规则与测试时保持待核验 |
| 电气/无线用途 | 是否带电/无线，型号、用途、符合性路径及文件 | 不给普通收纳盒套用电气认证 |
| 德国本地要求 | 德国销售场景、渠道、包装等本地事项是否需补查 | 当前EU案例不能冒充德国全覆盖 |
| 美国联邦与州 | 具体州、产品类别、销售对象是否明确 | FTC案例不等于所有州/品类规则 |
| 美国食品接触 | 食品接触用途、材料与支持文件是什么 | 不以FDA registered代替适用要求核验 |
| 英国地域 | Great Britain还是Northern Ireland，适用产品类别 | GB标志案例不外推所有英国地区 |
| 中国适用事项 | 境内宣传/供货或出口分别涉及哪些具体场景 | 当前未内置中国完整法规包 |
| 儿童用途 | 年龄、用途、警示与检测是否有依据 | 未接专项认证库，不能凭图片自行认定 |
| 医疗/治疗用途 | 宣称、实际用途、产品分类和授权范围 | 敏感词提示不能代替医疗器械专项审查 |
| 环保声明 | 涉及产品还是包装、条件、测试和生命周期范围 | US/UK/CA案例有限匹配，不能鉴定测试充分性 |
| Amazon | 站点、品类、当前规则版本与素材是否对应 | 原生审核以返回scope为准，不自动发布 |
| Alibaba RFQ | 客户需求、已确认报价和商务待确认项是否一致 | 不把报价草稿当客户已接受合同 |
| 社交平台 | 哪个平台、目标市场、内容形式、当期规则和图片权利 | 未接平台规则时明确未程序校验 |

证据复用前重新核对产品/版本、市场、用途、日期及正文变化。缺少资料写“待确认”，未查询写“未查询”，没有命中写“本轮有限规则未命中”；这三者不能写成“已全面通过”。
