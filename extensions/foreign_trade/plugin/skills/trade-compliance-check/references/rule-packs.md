# 首版规则包与扩展规范

当前packs.json版本starter-1，19条全部为internal_review_checklist，official_rule_verified=false。官方URL仅为后续研究入口，没有读取或核验当前正文；不在包内声称法规号、实施日期或义务已经得到验证。

- 通用：声明依据、主体产地授权、合同边界、交付文件、营销触达与个人数据。
- 欧盟：市场适用主题、食品接触、电气/无线适用路径。
- 德国：另加本地要求主题。
- 美国：联邦/州范围、食品接触主题。目的州与产品细类仍须补充。
- 英国：区分Great Britain/Northern Ireland再确认具体要求。
- 中国：宣传与产品要求主题。
- 高风险用途：儿童、医疗、环保声明。
- 渠道：Amazon站点类目、阿里国际站场景、社媒平台政策。

所有欧盟成员国可匹配EU主题，但除德国外仍提示国家规则包缺失。EU集合为路由配置，不代表政策实时更新。加拿大等未覆盖市场仍可运行通用检查，但必须报告当地覆盖缺口。不能把“没有选到规则”当作“无需遵守规则”。

## 添加检查项

规则包括id/title/version/basis/official_rule_verified，以及markets/categories/stages/channels/features/depends_on_text/evidence_request/official_research_entry。四个列表使用*代表通用；features为所需布尔用途条件。未知输入使该项potential，明确不匹配才排除。不要把未经确认的模型推断写成false。

新增国家或类别先收集实际业务场景，明确范围，再增加检查清单与回归测试。仅有清单条目时沿用internal_review_checklist；不能只把verified标志改为true就宣称已核验。本版引擎不支持自动法律解释，故输出仍标官方规则未验证。

如需维护正式法规包，须另附法规/政策ID、版本、官方原文与URL、辖区、产品及经营者角色、发布和实施/失效日期、过渡期、适用例外、核验人、核验日期、复核期限与替代关系，再经专项审核后扩展模型和测试。公告链接或证书关键词不能替代这些内容。

变更规则字段会改变rule_hash，使已有审核失效；升版保留旧版本到独立档案，不覆盖历史业务回执。来源/证据复核时间是企业内部维护规则，不能自动推断法规永久有效。

## 在已有工作流中的建议调用点

| 工作流 | 检查时机与stage |
|---|---|
| 获客 | 开发信成稿前，outreach |
| 背调 | 仅核对拟议交易的适用范围；信用制裁继续复用背调专项，不能用本清单替代 |
| 沟通 | 对外回复形成商业承诺前，communication |
| 谈单 | 报价、责任及付款条件准备确认时，contract |
| 复盘 | 用原阶段与历史as_of还原检查，另注明历史来源可得性 |
| 成交 | 合同/PI确认时contract，出货前shipment |
| 发品准备 | 当前平台/站点产品文案审核时，listing |
| 采购 | 样品、材料、供应商交付资料或采购条款确定时，procurement |

宿主现已通过共享提示按需调用检查，并在对话结果中显示未检查范围和待审核项。这仍不是发送/发布入口的强制拦截；独立脚本也不会改变其他工作流。
