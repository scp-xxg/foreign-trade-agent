# 高质量云端 3D 生成

通用入口，不限制服装或商品品类。使用专业图生/文生3D引擎，而不是让基础几何模板冒充精美模型。当前支持单图或文字生成一个候选；H3.1、12万面、PBR详细贴图由服务端固定并通过官方CLI估价，不能由提示词偷偷追加付费后处理。

1. 用户有参考图时，使用当前账号真实附件的file_id。网站链接用于查看风格和确认需求，不从付费商品站点抓取受保护模型；原创或用户有权使用的图片才能进入云端生成。已有高级服装模型若获授权，可另走导入改款，不能把它说成AI新生成。
2. 参考图/概念图不是3D模型。展示参考图必须使用reference.url或原附件真实/files地址，不要把/myspace或本机路径直接当网页图片URL。先展示或明确说明参考图作用，再调用tripo_prepare_asset(title,prompt,reference_file_id)。无图时可使用明确的prompt。检查官方预检valid、plan_id、estimated_credits；此时尚未上传或扣积分，不能说模型已生成。
3. 调用tripo_account_status。未登录时说明需要官方网页授权，密码/验证码/密钥不进聊天。本次预算未核验或不足时停止提交，不自动充值；免费模式只用已核验的免费额度，付费模式必须有用户明确授权的独立预算，不把网页会员积分或聊天模型额度当API额度。
4. 用户已要求实际生成且账号本次预算可用时（免费额度，或用户明确同意的付费额度）调用tripo_submit_asset(plan_id)。重复消息或超时均保留同一个plan_id，不能重新prepare再提交以绕过预算。submitting/submission_unknown表示结果不确定，不是失败后可以随意重发；通过原计划查询或请维护者核对任务。
5. 提交得到task_id后调用tripo_asset_status(plan_id,wait=true)。可等待90秒，未完成时继续查询同一计划；不重复生成。provider_failed如实说明。任务成功但delivery_pending只重试下载/渲染，不能新建云端任务。
6. completed以后才能宣称生成完成。GLB是Tripo真实输出；PNG是该网格在隔离Blender中实际渲染的结果，不用输入参考图冒充效果。提供工具返回的GLB、PNG、Blend真实/files链接，并展示PNG。报告模型来源、计划编号、实际消耗积分（若服务返回）、参考来源、局限。
7. 服装是外观网格，不保证可打版、真实合体或布料仿真。任何精度/画质问题应基于实际结果说明，不声称等于参考商品。二次改色/花纹/局部几何可转交现有Blender通用工具；需要再次云端生成时先重新核对用户意图和本次预算，不能静默消耗更多积分。

保留HugAgentOS和上游来源。不要索取模型参数中的账号、密钥或任意本机文件路径；工具账号和会话由HugAgent注入。
