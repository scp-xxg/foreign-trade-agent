# 发品准备六技能

能力中心 → 技能：产品资料标准化、平台类目与属性匹配、搜索关键词与发品规划、平台商品内容编排、商品图片与素材适配、发布前质量与规则检查。

在聊天中描述产品、平台、站点与语言，上传产品资料和图片；助手按需加载技能并调用trade_listing_prepare。原有商品导入与本地化能力继续复用。对话框「+ → 工作流 → 发品准备」开启六技能工作流，显示步骤、输入和交付说明；再次选择或关闭输入框标签可停用。与其他外贸工作流互斥。

六步骤为normalize→taxonomy→keywords→compose→media→preflight。共享来源与版本、独立SKU状态。平台规则需提供真实版本及有效期；未联网获取规则，规则缺失不放行。关键词搜索量无报告为未知；源文本和确认标记不能独立鉴真。

图片确实读取授权附件、检查并保持比例缩小、转换格式、输出附件；不包含OCR、自动型号识别、去背景、AI场景合成或图片翻译。商品文案复用已有能力后必须人工审阅；确定性工具只作字段/格式核对。

预检每次读取图片真实字节，审核sha256须与实际文件一致；review_scope_hash绑定除时间/审核记录外的整批输入，改产品、规则、草稿、关键词、图片或确认信息须重审。as_of单独控制过期判断。ready_for_publish_review表示所提供范围的检查完成，仍需发布审核，不等于平台接受或已上线。

各技能参考contract.md与真实模型生成的schema.json。衡量字段准确率、缺项/冲突召回率、类目属性准确率、关键词相关率、文案关键事实错误、图片规格通过率与预检误报漏报；业务效果未接入数据保持未知。


## 对话工作流与恢复

沿用现有对话编排机制，每次普通发送或排队发送会携带六技能流程要求；指令消息不注入。开关随当前聊天草稿保留，切换账号清空。开启仅选择流程，不立即运行；发送任务后按依赖执行六阶段真实工具调用。

本流程使用对话中的统一ListingInput与工具回执衔接，各SKU保留版本和来源。缺资料或需人工确认时暂停对应步骤，补充后从受影响阶段继续。进度由助手在回复中展示，不是独立后台作业或专用进度面板。图片转换输出需回填最终文件ID，重新核验图片并绑定当前审核范围。更改输入后重跑关联检查，不沿用过期审核。

示例：上传产品表和图片，选择发品准备，发送“为这批SKU准备阿里巴巴国际站英文商品，请先检查缺少哪些资料”。规则缺失时会列出需补充项，已有资料可先标准化；全部审核通过后输出待发布审核资料包，不实际发布。
