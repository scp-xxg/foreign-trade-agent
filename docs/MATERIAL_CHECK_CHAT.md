# 对话内资料检查

入口：输入框工具栏直接显示「资料检查」按钮。点击即检查当前文字和所选文件，弹窗标注敏感词，不发送聊天消息、不调用模型、不清空草稿。修改后可重新检查；切换账号会取消请求并清空结果。已有8个工作流生成拟对外草稿时，也按提示按需调用同一工具，不检查普通解释或每一轮内部提问。

工具：trade_material_check(action=sensitive|compliance,data,file_ids?)。复用敏感词与合规技能的脚本和规则文件，不复制另一份运行算法。工具需要当前账号启用的外贸插件和对应技能读取记录。附件必须属于账号且上传或明确引用于当前聊天，最多10份，每份8MiB。原生提取支持TXT/CSV/JSON/XLSX/PDF；图片未执行OCR，扫描件或截断资料明确显示覆盖缺口。其他文件需先通过可用文档工具提取并核对文本。

反馈一：真实工具检查的原文副本，按Unicode码点位置标注命中，点击打开规则原因及修改建议。不会把模型自由输出的JSON当卡片。候选标注不代表违法，未命中不代表合规。原文与模型其他回复分开，避免错误定位到改写后的另一段文字。

反馈二：合规卡片汇总范围内已核对、缺少证明、需复核、发现冲突四类，默认最多展示3个待处理项，其余折叠。没有资料或未读到图片文字时不显示全面通过。当前规则包是内部检查主题，未联网读取最新法律。

操作：查看修改建议、补充检查资料、重新检查最新资料均将带检查记录ID的请求追加到当前聊天输入框，保留已输入文字和附件。用户补充并发送后才继续，按钮不隐式发信、不批准、不自动改原文。修改建议由模型根据真实检测提出，先提供原文与改写对照；没有依据的数值/证书/交期不能补造。

历史：完整成功工具回执可以重新呈现；精简过的历史工具结果显示提示，请求重新检查最新资料。当前检查是对话快照，不是实时持续监控或持久审批账本。历史卡片不能代表当前文件版本已审核。

验证：后台工具与权限/附件测试、来源脚本回归、前端回执验证与Unicode边界测试、菜单和卡片浏览器交互测试、生产构建。浏览器测试使用真实算法生成的演示回执，未调用外部模型；模型是否按需执行检查取决于该轮工具调用，尚未作为发送/发布的强制校验闸门。

直接检查使用认证multipart接口，所选本地文件直接上传检查，导入文件按当前用户归属读取；支持检查尚未发送的草稿。旧的+菜单检查入口已移除。
