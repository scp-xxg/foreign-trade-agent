## 场景一：询盘、报价与跟进

本轮通过工作台 UI 完成以下流程，并对指定记录及实际下载文件作只读核验：

1. 查询 DESK-001，构造 500 件、标准包装、交付 Spain 的模拟询盘。LYRECO 的公开官网和 GLEIF 信息用于公司资料核验，不代表真实采购或合作关系。
2. 首次模拟报价为 USD 2400.00，生成待审双语回复草稿。
3. 建立 2026-10-29 09:00、`Asia/Shanghai` 的站内跟进待办。
4. 改为 1000 件、定制包装，重新报价为货值 USD 4800.00、包装费 USD 300.00、小计 USD 5100.00，再生成新版双语草稿。
5. 通过 UI 标记模拟客户已回复，原待办以 `buyer_replied` 原因取消。

最终询盘 revision 为 9，当前报价修订为 7；两种语言草稿均引用该报价，`stale=false`、`not_sent=true`。原 USD 2400.00 报价保留在历史中，待办取消时间与客户回复时间一致。

实际 PDF 为一页，中英金额和范围说明清晰。实际 Excel 含“中文报价单”和“English Quotation”两张表，数量、单价、包装费、货值及合计均为数值单元格且两表一致。模拟标记、运费待确认、不含运费及税费说明完整。下载文件只读核验前后哈希未变化。

以上证明工作台业务与导出链，不证明模型在聊天中连续完成这些步骤。

## 场景二：真实 Pi 资料的本地模板

通过 UI 上传 Raspberry Pi 5 的既有公开英语事实 CSV 和许可照片，确认 8 条事实后，显式选择 `generation_mode=template`。英语 CSV 原样取自原公开资料的英语列，保留来源与核验日期，没有增加或自行翻译事实。

最终资料包 revision 为 6，输出对应 source revision 5。实际下载核验包括：

- ZIP 恰含 8 个预期文件：文案、FAQ、事实、来源说明、上传资料清单及三张 PNG。
- 8 条事实与上传英语 CSV、指定资料包记录一致；FAQ 共 11 条，前 8 条答案对应事实，其余商务条件保持待确认。
- 三张图片分别为 1200×1200、1600×900、1200×1600；画面和文字清楚，未观察到裁切，单独下载的参数图与 ZIP 内同图一致。
- 制造商来源、SimonWaldherr 作者与 CC BY 4.0 许可保留；没有由照片推断 RAM 容量，也没有补造价格、MOQ、库存、交期或销售授权。
- 来源说明明确写明本地原文模板和未调用模型，输出仍标记未发布。单独下载的 FAQ 与 ZIP 内文件一致。

这验证了真实资料上传、确认、本地整理及实际文件下载；没有把它称作 AI 翻译或模型聊天验收。

## 场景三：岗位审核与内部交接

协同单复用场景一询盘和当前报价，并关联同一 DESK-001 的模拟资料包。资料包含 6 条英文模拟事实和 CC0 程序绘制几何示意图，显式本地模板输出 9 条 FAQ 及三种图片。

工作台 UI 完成六项任务的结果填写与逐项人工审核。最终协同单 revision 为 14，下载 JSON 与数据库一致：

- 业务、采购、美工、运营、合规五个岗位均有负责人标签；业务需求和最终交接分别有业务标签。
- 六项任务均为 `done`，审核意见、时间和当前用户操作人记录完整，审核顺序满足必需依赖。
- 来源版本分别为询盘 revision 9、报价修订 7、DESK 资料包 revision 3；重新计算的三个业务指纹均与引用一致，没有阻塞或失效任务。
- 六条未决事项和六条风险保留在 JSON 与 Markdown 中；任务结果、审核意见和来源标识与数据库记录一致。
- `scope=current_user_role_coordination`，`messages_sent=false`、`published=false`。岗位姓名是业务标签，不代表多人 ACL 或已通知其他人。
- LYRECO 公开公司信息与团队模拟交易分别说明；DESK 资料与同一模拟 SKU 绑定，Pi 公开规格未混入 DESK 资料，DESK 模拟价格也未套给 Pi。

实际 Markdown/JSON 下载只读核验前后哈希未变化。该结果为本地工作台 UI 协同验收，未声明 LLM 聊天链通过。

## DESK 图片措辞修复的单独记录

首次 DESK 浏览器 ZIP 的 8 文件、6 条事实、9 条 FAQ、三种尺寸以及来源/CC0 声明均符合约定，但通用图片模板仍写有 `Product reference photo`、`Original photo layout`，与图内“非真实照片”的示意图声明不一致。

代码随后将通用称呼及相应 FAQ 改为 `image`，保留原始作者和许可署名。使用已授权 DESK 记录及未修改原图，在新源码中进行显式本地模板重渲染：三张 PNG 和 8 文件 ZIP 均已检查，通用称呼正确、排版清晰、模型调用数为 0。原业务记录、原图和原浏览器 ZIP 未覆盖。

此复核标记为 `source_render`，`browser_redownload_verified=false`。**截至这份证据，不能声称旧 DESK 浏览器 ZIP 已重新下载并通过修正后验收。** 最终部署后的重新下载应另行追加实际证据，不能覆盖本轮原始观察。
