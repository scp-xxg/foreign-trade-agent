# 谈单工作流

入口：对话框＋ → 工作流 → 谈单。与获客、背调、沟通互斥，点击当前标签或同一菜单项关闭；状态按会话隔离，排队消息保存发送时快照。

四个新技能：商机诊断与谈判策略、异议诊断与处理、议价与条件交换、样品与试单推进。复用需求澄清、现有报价、答复、条款校验与纪要。先诊断再依赖情境执行，最后汇总当前卡点、依据、下一步及待审核决定。不是每轮都降价或寄样。

输入：客户往来及日期、目标、采购需求、报价版本、成本及币种单位、贸易术语费用、利润底线与授权、可交换条件和样品政策。工具只校验引用子串，字段语义及真实性需审核；不能把模拟报价成本当真实成本。

输出：有来源的阶段候选、异议及验证问题、内部Decimal毛利与授权检查、样品验证缺项及真实事件、对客待审草稿、条款检查与纪要。议价只支持同数量同币种口径比较，变更数量或融资条件需重算。模型组织策略和语言，工具不独立证明商务事实，也不发送、签约、寄样或持久化。指标无真实样本保持空值。
