# 私有敏感词库与生成后提示

本功能采用“私有知识库原文 + 确定性匹配”的组合。原文供智能体检索及核对上下文，生成后的扫描独立执行，不依赖模型是否记得主动调用自查。当前为提示模式：保留正文与事实，不自动删改、不强行拦截下载或发布；命中不等于违法，未命中不等于合规批准。

## 使用与覆盖

在本机“我的空间→私有知识库→外贸敏感词库 v4.0”查看上传原文、Wiki条目和来源。该库已绑定当前账号的外贸业务员、采购跟单员、商品运营专员，不更改其提示词及其他权限。

- 普通主聊天、直接角色对话和委派子智能体的最终回答：追加“敏感词提示”，列词、L级、字段位置和章节/规则号。
- 询盘报价（含仅报价、未生成草稿）、生成/修改草稿、商品资料的Listing与FAQ：自动扫描并保存提示，聊天卡片与工作台显示warnings。
- trade_review：增加“敏感词提示”分类，显示颜色风险、文字批注、来源章节/行号及认证原文链接，保留多轮审核。
- 图片扫描覆盖由资料包文案用于排版的文字；不会自动识别上传图片的OCR文字、地图、标识或视觉含义。
- 既有历史回答和旧资料不追溯改写；要检查旧稿，请对其发起新的审核或显式扫描。
- 扫描在完整生成结果形成后执行；流式过程中可能先看到部分原文，结束时追加提示。它不是发布前强制阻断器，外发仍由人工决定。

导入器安全解析第16章RULES字面量，不执行Markdown中的Python代码；另外提取明确词条表。当前v4.0编译306条（27条机器规则和279条明确词条），26章原文完整保留，未把图像、复杂语义和证据真实性条款冒充为全自动检查。

匹配有长度、数量和超时限制。出错或超限会提示“敏感词检查未完成”，不静默当作未命中；账户未配置词库时不套用别人的词库。

## 原文与规则的区别

原文中的L1–L4保留为词库风险提示等级，应用不会据此认定法律违规。包括CE、FDA在内的宣称需核对产品、监管路径和证据；不能把文件中的示例标准、认证、质保年数或性能参数直接补成商品事实。

认证表述参考核对了[欧盟制造商CE说明](https://single-market-economy.ec.europa.eu/single-market/goods/ce-marking/manufacturers_en)和[FDA审批说明](https://www.fda.gov/consumers/consumer-updates/it-really-fda-approved)。原文保持原样，不将其笼统说法冒充当前官方结论。

导入器修正了cures等词形、#1边界和CE-certified连字符匹配；豁免只作用于Best regards/Best wishes本身，不用附近的“FDA registered”或“compatible with”掩盖另一处真实命中。引用、否定与讨论词条时仍可能提示，应结合语境复核。

## 给自己的账号导入或更新

1. 在私有知识库上传自己的Markdown，等待原文索引完成；Wiki页生成是后续异步步骤。
2. 更新项目并执行正常数据库升级（ft_0002），沿用原app-home。勿复制维护者的数据库、账号或知识内容。
3. 用原文件、本人知识库编号和文档编号激活规则：

~~~bash
.venv/bin/python extensions/foreign_trade/import_lexicon.py \
  --app-home "$TRADE_APP_HOME" --username "$TRADE_USERNAME" \
  --file "/你的原始词库.md" --kb-id "你的kb_id" --document-id "你的document_id"
~~~

命令核对账号归属、文档索引状态、checksum及存储原始字节；规则和原文不一致时拒绝激活。同一原文重复导入复用版本，新版本替换当前激活版本并保留旧版本记录。知识库上传新版文件本身不会自动替换可执行规则，须显式再执行上述命令。账户角色如需主动查询该库，在角色编辑中绑定自己的知识库。

运行原文和编译规则只存在当前实例的私有数据中，不随Git分享。本仓库只提交通用扫描代码、集成、测试和操作说明。

## 认证接口

- GET /api/v1/foreign-trade/lexicon：当前账号配置、版本、来源SHA及规则数。
- POST /api/v1/foreign-trade/lexicon/scan：传fields对象，例如 {"fields":{"body":"Our best price. CE certified."}}；返回匹配片段、字段位置、L级与源章节。
- 原文通过其所属知识库认证文档接口访问，不公开文件地址。

## 本机验证

本机v4.0原文已通过SHA256校验，原始字节回读一致。原文19块、全部章节存在；Wiki完成16页、36链接、无失败，并成功搜索规则及白名单条目并取回对应原文。

25个原文示例的“是否提示”判定均符合预期；不宣称所有规则与法律含义因此已验证。普通聊天实测自动提示best price、CE certified、FDA approved、100% safe四处；Best regards及普通规格文本不提示。商品模板生成和真实审核报告均验证有可见提示，正文仍保留。整体公开/选定兼容回归716项和中文CE构建通过，报价路径补充后相关123项回归通过；最后增加批注容量耗尽的两项回归，相关后端与前端审核测试通过；另有前端审核高亮、emoji位置及卡片验证。
