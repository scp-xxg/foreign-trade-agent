# 复盘工作流

入口：对话框＋ → 工作流 → 复盘。与其他工作流互斥，点击当前标签或同一菜单项关闭；会话状态隔离，排队消息固定发送时的配置。

输入：单商机/周期范围、目标、起止日期、时区与统计截至时间、往来、报价、跟进、样品及订单原文证据；周期分析补充阶段定义、去重口径及固定观察期。

执行：业务过程还原 → 周期漏斗（单商机可跳过） → 赢丢原因 → 改进行动与实验设计 → 候选经验。工具名trade_buyer_research，操作及严格契约见五个技能。模型提取及组织策略，程序校验原文关联、时间、计划实际、成熟分母、Decimal转化、阶段耗时及动作/案例缺项。不能证明来源真实性和因果。

输出：证据时间线、版本与计划差异、周期活动量及同批转化的分子分母和待观察数量、按渠道对比、原因证据与反证、负责人/期限/验收/检查点、带适用条件反例版本及复查日期的待审案例。只统计本次材料，不假称读取全量CRM。客户沉默不等于丢单，完成动作不等于业务改善，单次案例不自动升级为通用打法。

当前输出为内部草稿，不发送、不自动写CRM或知识库、不修改技能、不建立提醒；实际入库和定时检查须在用户审核授权后接入对应真实工具。漏斗按商机计数，支持自定义适用阶段；阶段耗时仅已转化样本，不推断整体停滞时长。缺真实实验结果不计算效果或统计显著性。

验收：独立人工标注事件、原因与案例；人工对照统计。持续记录事件召回/准确率、统计正确率、无依据归因次数、行动完成与验收率、知识审核/采用/过期处理率。所有指标带样本数、分母和周期，无数据保持未知。
