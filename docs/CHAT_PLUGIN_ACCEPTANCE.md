# 外贸技能插件验收记录

验收日期：2026-10-21。范围为公开项目的 `foreign-trade-demo` 0.2.0；模型和账户配置不随仓库分发。

## 已验证的网页流程

- 聊天加载插件及六个业务工具；错误字段和未完整读取技能的调用被拒绝，没有产生业务写入。
- 纠正调用后，聊天保存了 LYRECO 演示询盘：DESK-001、500 件、标准包装、目的国 Spain。该询盘由团队构造，不代表 LYRECO 的真实订单。
- 独立的分步聊天调用原询盘的报价工具，得到 USD 2,400.00；询盘工作台显示相同记录、条件、版本和金额。
- 从聊天报价卡实际下载中英文 PDF 和 Excel；PDF 已渲染核对，Excel 已读回核对。刷新聊天后报价卡和下载按钮仍保留。报价明确标记模拟数据，运费和进口税费未确认、不计入小计。
- 聊天上传真实产品规格表和授权照片；资料包成功导入规格表、保留来源和照片署名，提取八项候选事实。候选事实没有被自动确认，也没有提前生成商品素材。

## 尚未通过的网页流程

当前配置下，模型仍出现错误字段、跳过技能读取、用操作说明代替工具执行等情况。连续多步执行还触发了上下文整理失败：结构化摘要返回不可解析的 JSON，原有框架降级摘要进一步阻止后续工具调用。

因此，本轮不能认定两条完整聊天流程已通过：

- 买家核验 → 回复草稿 → 跟进待办 → 改量重算，尚未在这次聊天链中连续完成。
- 照片导入 → 采用已确认事实 → 生成英文文案、FAQ、图片 → 从聊天下载资料包，尚未完成。已上传到聊天的照片不等于已经导入资料包。

不能把模型口头声称“已核验”“已生成”作为验收证据，也不能把独立工具测试或工作台测试替代为聊天全流程通过。

## 自动化覆盖与后续验收

自动化测试覆盖原生 Toolkit 到真实隔离业务服务的完整链路，包括改单重算、回复与跟进、附件归属、事实确认门禁、实际 ZIP/PNG/FAQ/文案导出、版本冲突和跨账户访问拒绝。内容生成的翻译提供方在集成测试中被替换为受控测试实现；该测试不证明任意在线模型都能完成工具编排。

摘要失败应明确标记本轮未完成、保留已经提交的结果，不创建虚构摘要、不自动重放写操作。相关修复只处理通用错误行为，不调整模型参数，也不保证压缩失败后可以自动继续。

该修复在本轮网页验收之后加入，使用故障注入回归验证；本轮没有再次重启正在使用的后端。因此，上述浏览器结果不作为修复后部署验收。下次部署仍需重启后端并重新登录。

更换模型或重新部署后，按 [聊天插件验收清单](CHAT_PLUGIN.md#验收清单) 重跑两条完整流程，并检查实际记录、刷新后的结果卡和下载文件。完整网页验收通过前，插件整合 PR 保持草稿，不能将此记录视为发布通过证明。
