# 提交版本说明

本版以“销售询盘报价 → 同款商品接力 → 运营上品资料”两条关联流程为主，保留 HugAgentOS 开源署名。Max-channel 的业务工作流已整合；其新版敏感词原文、扫描器和混合材料检查链路未引入，敏感词以本机实现为准。

已验证：
- 870 项后端与兼容回归通过；前端构建、报价/Excel、资料卡、审核卡和权限/版本保护测试通过。
- 全新 Docker 数据卷初始化、三岗位、8 个官方合规案例及原文检索、两条本地模板业务流程、ZIP/三图/审核报告、重启数据保留均通过。
- 本机真实模型完成公开买家核验、500 件标准包装 USD 2400 → 1000 件定制包装 USD 5100、跟进、RFQ 审核及双语修订稿保存、同款岗位接力。
- 真实运营岗位已生成同款英文资料、9 条 FAQ 和三种图片，实际模式为 ai_grounded；一次上游请求失败后读取当前状态并重试成功，未重复创建资料包。
- 询盘只读展开后展示原生报价下载卡的修复已完成构建和专项测试，下载前再次核对当前账号权限与报价是否变化。

提交时的验证边界：
- 最后一轮真实模型的 Amazon 修改复审及全部网页按钮下载，因提交时间限制未逐项跑完；对应的数据库、模板、导出和审核能力已在隔离实例及自动测试中验证。
- 聊天编排和 AI 生成需要自己配置可用模型；模型或外网临时故障不能由本地代码消除。无模型时可从工作台使用明确标注的本地模板与确定性计算/审核。
- 原图/示意图排版不等于 AI 写实生图；基础资料 ZIP 与最终平台审核稿分别保存。
- 合规案例为带日期的官方来源摘要及辅助核验，不是认证、平台批准或完整法律审查。
- 不包含账号、密钥、数据库、真实客户资料、日志或维护者私有敏感词原文。公开合规案例随首次初始化导入；企业自有资料和词库按文档导入。

运行见 ONE_COMMAND_DEPLOY.md；可复制问答见 DEMO_TWO_WORKFLOWS.md；一页方案位于 submission/SailAgent-one-page.pdf。
