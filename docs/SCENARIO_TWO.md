# 场景二：产品资料转英文上品内容

推荐入口：在聊天中选择“外贸业务助手（演示）”并上传产品资料与原图，核对事实摘要后确认生成；产品内容工作台继续显示和编辑同一资料包。完整用法见 [对话插件指南](CHAT_PLUGIN.md)。

入口为侧边栏「产品内容工作台」。本场景沿用公开 CE 项目的账号、文件存储、模型配置、产品查询和询盘报价能力。

## 可复现演示

1. 运行 `python extensions/foreign_trade/team.py setup` 更新依赖、安装和网页构建，按团队部署文档启动。已部署队员先拉取更新，再执行 setup 并重启服务。每人自己的账号、模型配置和业务记录独立保存。
2. 打开「产品内容工作台」，选择真实示例，下载示例 CSV 和产品照片。具体来源、作者和许可见 [SCENARIO_TWO_SOURCES.md](SCENARIO_TWO_SOURCES.md)。示例是 Raspberry Pi 5；不据照片猜测 RAM 容量，不表示我们与制造商存在供货或经销关系。
3. 建立资料包，真实上传 CSV 和照片。CSV 的结构化内容先成为候选事实，用户核对原始材料和来源，再采用、编辑并保存。支持普通 UTF-8 TXT/CSV/JSON、XLSX、带文本层的 PDF，以及 PNG/JPEG/WebP。扫描 PDF 需要先自行转文字，本版本不提供 OCR。
4. 确认产品名称、品牌、型号、事实及来源 URL，补充图片作者、许可和来源署名。事实最多 20 条；不把来源链接本身当作独立核实完成。
5. 勾选事实核对确认，生成英文资料。配置的 `main_agent` 模型只翻译确认后的事实；程序组合标题、卖点、描述和 FAQ。新增数值、丢失数值、缺失事实或格式异常会触发明确的模板回退，回退保留原文并提示尚未翻译，不冒充模型成功。
6. 查看三种基于最后一张上传原图生成的排版图：1200×1200 方图、1600×900 横图、1200×1600 参数图。图片仅等比缩放、排版并添加事实文字，不改变产品结构；完整事实保存在文案和资料包中。
7. 下载英文 Markdown、客服 FAQ CSV、单张 PNG 或 ZIP。ZIP 包含文案、FAQ、事实 JSON、图片来源说明、上传资料清单及三张 PNG。资料清单保留文件名、校验值、上传时间和提取文字，图片的校验值对应实际用于排版的规范化 PNG。带有图片许可信息，CSV 对公式起始字符做文本处理。译文未完成时只提供明确标注的原文模板，不生成乱码英文图片。
8. 刷新页面，重新打开资料包，确认文件、事实和生成结果保留。修改资料或上传新文件后，旧输出立即失效，重新确认、生成后才能下载。

## 与查询、报价的衔接

工作台可查询现有模拟产品目录，并以明确的数量、包装、目的国创建场景一询盘。进入「询盘工作台」后，沿用现有计算、回复草稿和中英文 PDF/Excel 导出。真实外部产品资料与模拟目录是两类来源：Raspberry Pi 5 的事实不与 DESK-001 等演示 SKU 自动匹配，也不套用它们的模拟价格。真实产品缺失价格、MOQ、库存、交期、运费和保修时，FAQ 提示向供应商确认。

## 数据边界与实现范围

- 资料包和文件按当前账号隔离；写入带修订号，冲突时要求刷新，不覆盖别人的修改。
- 图片会解码、限制大小和像素并重新编码；本功能不执行文档中的脚本、链接、宏或模型指令。
- 来源是可供人核验的引用。本版本不声称自动认证厂家身份、规格真实性或图片授权；用户必须核对。
- 所有文案及图片是待审核草稿，不自动上架、不发信，也不向任何平台承诺价格、交付或认证。
- 图像采用本地排版模板，不依赖额外生图账户；模型只用于事实翻译，不识图推测规格。
- 文件及记录存于部署者的应用数据目录，不进入 GitHub。仓库仅包含公开源代码及带署名的公开示例素材。
- 保留 HugAgentOS 的开源署名、LICENSE 和 NOTICE。
